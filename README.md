# ATLAS GRID

AI persistent memory and knowledge graph platform powered by MiMo V2.5 + Hermes Agent.

## Architecture
- **Encoder** — Ingests conversations, documents, and actions into structured memory traces
- **Indexer** — Builds a semantic knowledge graph with entity relationships and temporal context
- **Retriever** — Surfaces the most relevant memories using hybrid vector and graph search
- **Synthesizer** — Fuses retrieved memories with current context for coherent, grounded responses

## Tech Stack
- MiMo V2.5 (long-context memory reasoning)
- Hermes Agent (orchestration layer)
- Claude series (language understanding)
